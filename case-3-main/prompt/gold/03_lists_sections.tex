\section{Описание системы}

В рамках практики были поставлены следующие задачи:
\begin{itemize}
    \item изучение структуры предприятия;
    \item участие в разработке аналитической платформы;
    \item приобретение навыков работы с хранилищами данных.
\end{itemize}

\subsection{Конвейер ETL}

Единый конвейер включает шаги:
\begin{enumerate}
    \item \textit{EXTRACT} --- выборка данных из источника;
    \item \textit{LOAD} --- загрузка в ClickHouse;
    \item \textit{SEMANTIC} --- генерация описаний колонок для LLM;
    \item \textit{DOCS} --- индексация документации в RAG.
\end{enumerate}
