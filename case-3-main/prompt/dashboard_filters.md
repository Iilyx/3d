Сопоставь одну фразу пользователя с каталогом фильтров дашборда.

Верни только JSON: {"pull": true или false, "filters": {"Имя": "значение"}, "say": "одна фраза"}

say — живая фраза в чат: что открываешь и какой период назван. Своими словами, не шаблон «Сейчас открою.». Если период не назван, скажи, что открываешь дашборд как он сейчас настроен.

pull = true, если фраза просит открыть дашборд/анализ или снять его данные за период (в том числе если в каталоге уже есть непустой блок result). Фильтр в фразе не обязателен.
Если фраза только открывает дашборд и не называет значение, верни {"pull": true, "filters": {}}.
В filters только те имена из каталога (name или alias), которые фраза назвала.
Значение — подпись варианта (value) или его key, и только если это слово есть во фразе. Короткий год «25» можно сопоставить с вариантом каталога, который кончается на эти цифры.
На сервис уходит key варианта, не подпись. Подпись «Февраль» при key «2» — это month: 2.
Не добавляй фильтры, которых фраза не называет. Остальные поля возьмёт код из value каталога.
Если это не просьба про данные дашборда, верни {"pull": false, "filters": {}}.
