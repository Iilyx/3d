# Structure — Campaign / paid status (Atelier)

Hint only. Use `compare` when Source has a pair (scale vs pause). Status words `Масштаб` / `Пауза` / `Держать` only when Source supports that call. Numbers ⊆ Source.

1. `title` — week thesis + hero KPIs
2. `scorecard` — this week snapshot; every KPI has `delta` and a `hint` sentence
3. `compare` — two cards only: what to scale, what to pause. `body` is 1–2 sentences
4. `table_hero` — creatives; last cell is exactly `Масштаб`, `Пауза`, or `Держать`
5. `chart_hero` — one trend
6. `card_row` — next-week bets + ask caption
7. `bullets` — ops checklist
8. `callout` — watch / trigger
9. `closing` — Friday review

Keep it ≤10 slides when Source is a weekly brief. Not investor narrative.
