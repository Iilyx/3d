# Structure — Performance (Bold Signal DNA)

Hint only. Lead with a chart when a chart id exists. Otherwise open on the scorecard or the table. Numbers ⊆ Source.

1. `title` — Spend. Return. Next move.
2. `chart_hero` — spend vs return (**before** scorecard)
3. `chart_split` — efficiency story
4. `scorecard` — once (spend / revenue / ROAS)
5. `table_hero` ×2–3 — channel / campaign / realloc
6. `card_row` — recommendations + orange gate
7. `callout` — incremental proof / caveat
8. `table_hero` — 90-day roadmap
9. `closing` — hero ROAS + caveats

Do not open like a board ask or workshop agenda. ≥5 layouts when ≥8 slides.
