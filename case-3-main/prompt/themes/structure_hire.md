# Structure — Hire

Hint only. Use a block when Source has that shape. Numbers ⊆ Source.

**Often fits a hiring brief:** the board question first, two sides only when Source has both, one decision at the end.

1. `title` — the hiring question in one line.
2. `callout` — the ask, one sentence.
3. `compare` — only when Source has two real sides. Otherwise skip.
4. `bullets` — the facts, one sentence each.
5. `scorecard` — the numbers as written, no invented delta.
6. `quote` — one sentence from Source, if there is one.
7. `section` — what changes if the hire happens.
8. `closing` — the decision, one phrase.

Do not invent a second column. Do not compute a delta.
