# Structure — Investor Update (Relay Ink DNA)

Hint only. Use `stat_hero` when one number should dominate. Use `scorecard` when several KPIs are peers. Numbers ⊆ Source.

1. `title` — quarter thesis
2. `section` — one-sentence quarter
3. `stat_hero` — the one number a partner should remember, plus 2–4 Source sentences
4. `chart_hero` — compounding curve
5. `table_hero` — engines or quality
6. `chart_split` or `table_hero` — GTM / conversion
7. `callout` — **the ask**
8. `card_row` — risks (threat / response / trigger)
9. `closing` — 3 caveats

Tone: confident, ice-blue, lots of air. ≥5 layouts when ≥8 slides.
